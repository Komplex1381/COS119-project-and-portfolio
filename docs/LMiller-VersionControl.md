## Topic: Version Control & Git

Version control, also known as revision control, records changes to a file or set of files over time so that you can recall specific versions later. In this class, we are learning Git. Update the information below where indicated.

**1. There are three types of version control.**

The three types of version control are Local, Centralized(CVCS), Distributed(DVCS). Local basically involves saving the files on your own machine with different names like working on a word document that you need to update and keep track of what version you are on update wise. Centralized has multiple developers accessing a single server and checking out the latest piece of code to work on. This way is controlled by an administrator. Distributed makes a copy of the main code and allows multiple developers to work on the code on their own machines and merge it back with the main code tracking who made what changes.
